Privacy notice

Personal Instinct Bridge is a private installed utility, not a public data service. This notice describes the utility separately from this static information website.

Data and purpose

After explicit account authorization, the utility uses Gmail read-only and send permissions to retrieve command messages and deliver relay notifications or results. It processes bounded message context, identifiers, timestamps, and execution receipts for that configured workflow. Only explicitly configured mail and assistant destinations receive operational content.

Storage and control

Operational processing occurs on the private host. Runtime credentials are retrieved from a separately scoped secrets vault. A private local ledger stores pending payloads, replay guards, and receipts. Accepted delivery payloads are removed from the local outbox; unresolved jobs can remain for reconciliation. Receiving mail and assistant services may retain transmitted content under their own policies.

Restrictions

The utility does not sell Google user data, serve advertising, or use that data to train its own models. Its use and transfer of information received from Google APIs adhere to the Google API Services User Data Policy, including Limited Use requirements. Revoking the app in Google Account permissions prevents future authorized API access; stopping the installed service prevents further relay processing. Retained copies at configured destinations are managed separately.

This website

This website contains no operational data, credentials, contact records, or account details. It has no scripts, analytics, cookies set by this page, forms, or login. Its static hosting provider may process ordinary HTTP request metadata. This website cannot access a mailbox or the private utility.
