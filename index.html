Personal Instinct Bridge

A private, locally operated mail relay. This website supplies application information only. It does not provide access to the application or its data.

Purpose

The installed utility reads an explicitly authorized mailbox and sends context notifications or command results to an explicitly configured assistant service. Mailbox permissions are limited to read and send. The utility has no mailbox deletion, calendar, or file-storage permissions.

Access

There is no public signup, login, command endpoint, upload form, or data browser on this site. The operational application and its credentials are not hosted here.
